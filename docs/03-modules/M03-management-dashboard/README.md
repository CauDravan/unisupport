# M03 – Management Dashboard

## 1. Purpose

Management Dashboard là module dành cho Management để theo dõi tình hình xử lý Request và đánh giá hiệu quả hoạt động của các Department. Module cung cấp số liệu thống kê, thông tin Request quá hạn và các báo cáo hỗ trợ việc ra quyết định.

## 2. Actors

- **Primary Actor:** Management.

## 3. Main Capabilities

- Request Overview.
- Overdue Request Monitoring.
- Request Statistics.
- Department Workload Monitoring.
- Service Performance Reporting.

## 4. Dependencies

- **M01 – Student Portal:** Cung cấp dữ liệu Request và Feedback của Student.
- **M02 – Staff Workspace:** Cung cấp dữ liệu về Assignment, Status và quá trình xử lý Request.
- **M04 – Security and Access:** Kiểm soát quyền truy cập dữ liệu và chức năng dành cho Management.
